## Experiment Title

Experiment 5

## Aim

To write a program to demonstrate tuple and related functions in Python.

## Algorithm

1. Define a function `calc(x, y)` that returns the sum `x + y` and difference `x - y`.
2. Display a menu and read the user's choice `n`.
3. If `n == 1`:
   - Read two integers `x` and `y`.
   - Call `calc(x, y)` and store the returned values.
   - Print the sum and difference.
4. If `n == 2`, print "Exiting".
5. Otherwise, print "invalid input".

## Output

Sample run:

```text
Enter choice:
1. Calculate
2. Exit
1
enter x: 5
enter y: 3
X + Y:  8
X - Y:  2
```
