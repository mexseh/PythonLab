## Experiment Title
Experiment 3

## Aim
To write a Python program to perform basic string operations.

## Algorithm
1. Assign a string to the variable `text`.
2. Convert the string to lowercase using `lower()`.
3. Convert the string to uppercase using `upper()`.
4. Convert the string to title case using `title()`.
5. Swap the case of characters using `swapcase()`.
6. Capitalize the first letter using `capitalize()`.
7. Find the length of the string using `len()`.
8. Split the string into words using `split()`.
9. Replace `"BCA"` with `"BCA-General"` using `replace()`.
10. Find the index of `"Jain"` using `index()`.

## Output

```text
Lowercase: i'm pavan, studying bca in jain university
Uppercase: I'M PAVAN, STUDYING BCA IN JAIN UNIVERSITY
Title Case: I'M Pavan, Studying Bca In Jain University
Swapcase: i'M PAVAN, STUDYING bca IN jAIN uNIVERSITY
Capitalize: I'm pavan, studying bca in jain university
Length: 42
Split: ["I'm", 'pavan,', 'studying', 'BCA', 'in', 'Jain', 'University']
Replace: I'm pavan, studying BCA-General in Jain University
Index of 'Jain': 26
```
